# Distribution Copy Templates

Use these templates for each weekly report launch. Keep the voice factual, measured, and directly tied to the published report.

## Tone guardrails

- Write with confidence, not certainty.
- Anchor each claim to report findings.
- Avoid hype language or implied performance guarantees.
- Keep calls to action clear and low-friction.

## X weekly post template

```text
Weekly Crypto Pulse — [Week of YYYY-MM-DD]

This week: [single-sentence market context from the report].

Key points:
• [Insight 1]
• [Insight 2]
• [Insight 3]

Read the full report: [Report URL]
Methodology: [Methodology URL]

#Bitcoin #Ethereum #Crypto
```
